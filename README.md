# Algorithm-Sandbox
A working repository mainly used to explore and learn algorithmic design and implementation. Based on Guide to Competitive Programming by Laaksonen


| File Name | Description | 
| --- | --- | 
| Maximum Sub-Array Sum | Demonstration of solving a maximum sub array sum problem with varying levels of time complexity ranging from $O(n^3)$ to $O(n)$. Also known as Kadane's Algorithm |
